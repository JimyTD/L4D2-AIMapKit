# 试玩发布版：人工指南

这份指南是通用的，不写某一关的内容；每一版包含哪几关、做到哪一步、导航网格的情况，看 `release/CHANGELOG.md`。agent 不启动游戏、不上传，下面这些由你来做。

## 1. 装好了没有

- `kit release` 把插件 `<名字>.vpk` 放进了 `<游戏>/left4dead2/addons/`。游戏开着的时候装不进去（文件被锁），关掉游戏再让 agent 跑一次。
- 启动游戏，主菜单 → 附加内容（Add-ons）：能看到这个战役，勾上。
- 同一个战役只留一个版本：旧版本的 vpk 已经被新的覆盖（同名）；要是你手动改过名字，把旧的删掉。

## 2. 怎么开始

- 主菜单 → 战役 → 自定义战役（或“附加内容战役”），选这个战役，从第一关开始。
- 单开某一关：开控制台，`map <地图名>`（地图名见 CHANGELOG）。单开不用 mission 文件，但换关、战役结算要从第一关开始才对。
- 和朋友一起玩：每个人都要装同一个版本的插件。

## 3. 看什么

- 机器已经查过的（走得通、门够宽、按钮按得到、事件顺序、换关、文字、摆件穿插、缺资源）不用你重查；进游戏发现了这类问题，说明检查有缺口，照常反馈，agent 会转给 Kit。
- 你来看：手感（跳、爬、走位舒不舒服）、好不好看、电脑队友和感染者走不走得动、节奏、声音、提示说得清不清楚。
- CHANGELOG 里写着“导航要重做”的关：感染者、电脑队友可能卡住或不出现，换关可能不触发。这是已知的，不用报；要试这些，先按项目 HUMAN.md 里导航网格的方法重做。
- 最后一关是临时终局：全员走到终点就结束，不是坏了。

## 4. 怎么反馈

每条一行：版本号、地图名、`getpos` 的输出（控制台打 `getpos`，复制那一行）、看到了什么、觉得应该怎样。截图放在同一行后面。agent 按坐标查回设计数据，分给对应的线处理。

## 5. 导航网格（要重做时）

按项目 HUMAN.md 里导航网格的方法：单开那一关，`sv_cheats 1`、`nav_generate`，等它跑完自动保存，再按 HUMAN.md 标起点、安全屋属性；做好的 `<地图>.nav` 从 `left4dead2/maps/` 复制到项目的 `nav/`，告诉 agent，下一版沿用。
