L4D2 自定义战役。用 L4D2 AIMapKit 设计，进度见 PROJECT.md。

| 目录 | 内容 |
|---|---|
| `sources/` | 资料库：原始证据和索引 `index.json` |
| `findings/` | 按对象整理的结论，引用资料编号 |
| `standards/decisions.json` | 待决定列表：本项目定的数值 |
| `design/plan/` | 规划：DESIGN.md、campaign.json、每关源文件、规划视图 |
| `design/detail/L<n>/` | 每关详设：结构体、开放区、事件、总图、spec.json |
