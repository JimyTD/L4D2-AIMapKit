# 链路 2：搭建手册

版本：0.1（2026-11-09）

**状态：待定义。** 链路 2 把链路 1 的搭建规格变成能玩的地图：先做白模（只有墙、地、门、楼梯），进游戏验证尺度、路线和节奏；再摆放道具、贴图、做材质。它调用链路 3 的工具。术语见 [../OVERVIEW.md](../OVERVIEW.md)。

**已知要回答的问题**：

1. 贴图来源：原版材质、开源材质库（如 CC0 授权的 PBR 材质）、AI 生成、实地拍摄，各自的质量、成本和授权。网络照片版权归原作者，只能作参考。
2. 怎样让贴图接近真实外观：按照片取色、匹配图案和尺度。
3. 无缝平铺、法线贴图、Source 的材质参数（VMT）。
4. 标牌、门牌、校名这类带文字的贴图怎么做。
5. 怎样按用途（墙、地、天花板）批量分配材质。
6. 构件模块（门套、高窗、吊顶灯格等）的建模标准。
7. 白模验收的流程：哪些问题退回链路 1，哪些在链路 2 内解决。

## 贴图来源的初步对比（2026-11-06）

**样本**：一张室内走廊照片的地面和墙面（灰色细颗粒石材地面、浅色涂料墙）。同一个 2.6 m 宽的走廊模型，换三种贴图，在 Blender（Cycles）里各渲染一张，与照片对比。

| 方案 | 来源 | 授权 | 贴图与照片色差 ΔE（地面 / 墙面） |
|---|---|---|---|
| A 原版 | L4D2 自带材质（`tile_mall_floor00`、`plaster_int_05`） | 随游戏，可用于地图 | 11.2 / 9.8 |
| B CC0 原样 | ambientCG（`Granite002A`、`PaintedPlaster017`），1K PBR | CC0，可随意使用 | 14.5 / 5.0 |
| C CC0 调色 | B 按照片对应区域的 Lab 均值和方差调色 | 同上 | 0.2 / 0.2 |
| D AI 生成 | — | — | 未测：本机没有图像 API 密钥 |

ΔE 小于 2 人眼基本看不出差别，大于 10 明显不同。

**结论**：

1. **调色本身可行**：CC0 材质按照片取色后，颜色可以对得很准；转成 VTF + VMT 进 vbsp 编译通过，没有缺材质。
2. **CC0 的纹理比原版更对**：照片里是灰色细颗粒石材地面，原版没有类似材质，最接近的是米色大方砖。原版材质库偏美式场景，非美式场景常常找不到对应的材质。
3. **渲染对比没用好**：三种方案的渲染图与照片的色差都在 16–39，差别主要来自灯光和曝光，不是贴图。照片里的颜色还混进了反光和相机白平衡，按它调色会把地面调得偏棕。改进方向：先校正照片白平衡；只比较贴图本身，不比较渲染；最终观感在 Hammer 或游戏里确认。
4. **最重要的发现**：一个室内场景让人一眼认出来，主要靠的不是地面和墙面的贴图，而是**构件**：门套、门上方的高窗、墙上的面板、吊顶和灯具的排布、踢脚线、地面反光。所以链路 2 的重点应该是“少量准确的材质 + 一套可复用的构件模块”，而不是追求贴图本身更逼真。

**还没验证**：AI 生成贴图；构件模块按照片尺寸建模后能否显著提高辨识度。下一步的最小验证是：只给同一条走廊加上照片里的主要构件，与照片并排对比。
