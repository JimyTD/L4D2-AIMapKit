L4D2 AIMapKit：设计线与生成线流程

设计线：从“一个主题”到“可交给生成的整关规格”。生成线：从 spec.json 到成品关卡。给人看的说明；agent 按 SKILL.md 和 references/ 工作。会话怎么分、问题怎么交回，见 references/sessions.md。
脚本机器门槛：脚本退出码 0 才能往下拍板用户门槛：交评审页，拍板后写进拍板记录子 agent可以并行派出循环逐个重复
点左边任一步，查看：拍板（停不停、要你定什么）、输入、要做的事、用哪些脚本、交什么、怎样算完成、能派什么子 agent、常见坑。

各步怎么拍板

用户不是关卡设计师：只在“只有你能定”或“有依据可看、有建议可选”时停下。要你回答的问题一律放在消息最前面；规划里写定的、不在路线上的不问；画的过程中不停。停下来是讨论，可以来回几轮。
拍板记在项目里：design/approvals.json 记哪个单元、哪天拍的（kit approve 写，之后文件改了 kit status 会提示“拍板后已修改”）；design/REVIEW-LOG.md 记你说了什么，每条标“AI 本可避免”或“只有用户知道”。agent 照着做的规则在各步骤页的“拍板”和 references/review.md，这张表是给人看的摘要。
