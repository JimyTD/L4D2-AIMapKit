# G6 布景与叙事（每关一次）

**目的**：每个建出来的空间做得符合它的设计和用途；道具、贴花、散落物按参照和摆放规则摆，脚本核对摆放，再由不知道设计的盲审看画面认房间。这一步不停顿。

## 读

G2 的参照板；G5 的模型清单 `work/models.json`；美术规范的摆放规则；kinds.json 里 need 含 dressing 的元素（space、atmosphere、interior）；结构体的室内意图（`interiors`，在 .build.json 里）；开放区和结构体的空间、路线、门。

## 做

1. **布景设计文件** `work/L<nn>/dressing/<段或结构体>.json`，每组一条：挂靠的设计元素（elements.json 的 key；室内挂室内意图的 key；路线写 <开放区 id>/route/main）、排法（规范里的哪种）、模型或贴花、数量、参照编号、依据（参照编号，或 atmosphere、事件的 key）。摆什么、怎么摆、墙地顶用什么，按室内意图写的用途和现状自己判断；意图写了 `must` 的照做。设计改了，按 key 找到受影响的组，只改这些组。
2. **按摆放规则摆**：朝向跟数据走（沿线、靠墙的对齐长边，正面朝房间或路）；不随机转角；立着放，倒着的只放在设计写了“倒着”的地方；成堆的东西按规范里的几种排法选一种。
3. 布景挂在空间、门、路线上，不写死坐标。
4. **叙事痕迹按美术规范的旧化分档**：第 1 档（刚出事的痕迹：倒、散、血迹、半开的门）只放在设计数据写了的地方，每组必须引用那条 atmosphere 或事件的 key；没写的地方只做第 0 档（日常磨损）；第 2 档（损坏）只在设计点名时用。脚本检查：第 1、2 档的组都有引用。
5. **不设密度门槛**：多少、多满由用途决定。设计写了为什么空的照做；没写空的房间做得空空荡荡，就是不符合用途。
6. **碰撞**：设计数据里的 fixtures、objects 按它的 blocks 字段决定挡不挡（翻不过去的按 G5 的 playerclip 条件）；布景自己加的物件用模型自带的碰撞，水平投影长宽都小于 dressing_noclip_max_u 的改成不碰撞。
7. **摆放核对**（脚本，每次生成后）：模型方向和数据方向差 ≤ placement_yaw_tol_deg；模型占地和数据外包重叠 ≥ placement_overlap_min；没写“倒着”的不许侧倒；高度和穿墙按 [G9](G9-delivery.md) 硬标准第 11、13 条的同一套判定先查一遍（贴墙摆的在 placements.json 标出来）。另出一张俯视核对图（数据外包、模型占地、正面朝向，错的标红），交评审前先自己看。
8. **室内盲审**：每个房间在编译后的地图里取人眼高度、不带任何标注的画面（渲染或截图，一间一到两张）。派一个主模型档子 agent，不给设计、模型名和平面图，只给画面，逐间回答“这是什么房间”。主会话拿回答和设计的用途比：对得上算过，对不上就改了重审。结果写进 `work/L<nn>/interior-review.json`：`[{"key", "images", "answer", "match": true|false, "fix"}]`。同一间改两次还不过的停止重试，交 G9。带标注的平面图、模型清单不能当盲审材料：写着什么就能答出什么，看不出房间空不空。

## 产物

布景设计文件；布景平面图；`build/L<nn>/placements.json`（摆放记录）；俯视核对图 `build/L<nn>/check/placement_*.png`；室内盲审画面和记录 `work/L<nn>/interior-review.json`。

## 交给下一步

摆放记录 placements.json；灯具类模型的位置清单（脚本，从布景文件里的灯具组导出，带 lit），G7 按它放光源，不另找。

## 完成

剔除 0（出界、压路线、挡门、重叠）；摆放核对 0 条错；每组都有挂靠的 key 和参照编号，第 1、2 档的组都引用了设计数据；每个建出来的空间都有盲审记录，没过的（改两次仍不过）交 G9。脚本未覆盖的项，由本步 agent 核对，结果写进 `work/L<nn>/manual-checks.md`。

## 子 agent

**主模型档**：室内盲审，一栋楼一个，只给不带标注的人眼高度画面，交回每间“这是什么房间”。

## 常见坑

- 随机撒点：没有设计意图。
- 按“每个 key 挂了布景组”交差：覆盖率全过，房间还是看不出是什么。
- 拿写着模型名的图当盲审材料：答案是读出来的，不是看出来的。
- 布景写死坐标：设计一改就落空（要挂在空间、门、路线上）。
- 规范只写“做什么”不写“怎么摆”：生成器自己发挥，随机转角、成片侧翻。
- 没有俯视核对图：摆错只能靠负责人在编辑器里发现。
- “看得出出了什么事”这种写法：每段都撒血迹，痕迹和设计对不上。
