# G6 布景与叙事（每关一次）

**目的**：按设计的室内意图把每个空间做成它该是的房间；道具、贴花、散落物按参照和摆放规则摆，脚本核对摆放，再由不知道背景的盲审认房间。这一步只有脚本门槛，不停顿。

## 读

G2 的参照板；G5 的模型清单 `work/models.json`；美术规范的摆放规则；kinds.json 里 need 含 dressing 的元素（space、atmosphere、interior）；结构体的室内意图（`interiors`，在 .build.json 里）；开放区和结构体的空间、路线、门。

## 做

1. **布景设计文件** `work/L<nn>/dressing/<段或结构体>.json`，每组一条：挂靠的设计元素（elements.json 的 key；室内优先挂室内意图的 key，并写对应 `has` 的第几项；路线写 <开放区 id>/route/main）、排法（规范里的哪种）、模型或贴花、数量、参照编号、依据（参照编号，或 atmosphere、事件的 key）。室内意图 `has` 的每一项都要有组，做不了的写明理由；`first_sight` 写的东西要摆在那扇门看得见的地方；`surfaces` 交 G5 的外观规则，不能沿用别类房间的墙地顶。设计改了，按 key 找到受影响的组，只改这些组。
2. **按摆放规则摆**：朝向跟数据走（沿线、靠墙的对齐长边，正面朝房间或路）；不随机转角；立着放，倒着的只放在设计写了“倒着”的地方；成堆的东西按规范里的几种排法选一种。
3. 布景挂在空间、门、路线上，不写死坐标。
4. **叙事痕迹按美术规范的旧化分档**：第 1 档（刚出事的痕迹：倒、散、血迹、半开的门）只放在设计数据写了的地方，每组必须引用那条 atmosphere 或事件的 key；没写的地方只做第 0 档（日常磨损）；第 2 档（损坏）只在设计点名时用。脚本检查：第 1、2 档的组都有引用。
5. **不设密度门槛**：多少件、铺多满由室内意图决定。本来就该空的空间按 `empty` 做；没写空的地方空着，是没做完。
6. **碰撞**：设计数据里的 fixtures、objects 按它的 blocks 字段决定挡不挡（翻不过去的按 G5 的 playerclip 条件）；布景自己加的物件用模型自带的碰撞，水平投影长宽都小于 dressing_noclip_max_u 的改成不碰撞。
7. **摆放核对**（脚本，每次生成后）：模型方向和数据方向差 ≤ placement_yaw_tol_deg；模型占地和数据外包重叠 ≥ placement_overlap_min；没写“倒着”的不许侧倒；高度和穿墙按 [G9](G9-delivery.md) 硬标准第 11、13 条的同一套判定先查一遍（贴墙摆的在 placements.json 标出来）。另出一张俯视核对图（数据外包、模型占地、正面朝向，错的标红），交评审前先自己看。
8. **房间布置图**（脚本，每个空间一张）：平面上画墙、门、模型轮廓并标模型名，旁边列墙地顶用的外观规则，写到 `build/L<nn>/check/room_<结构体>_<空间>.png`。
9. **室内盲审**：派一个主模型档子 agent，不给室内意图和设计背景，只给一栋楼的房间布置图，逐个空间回答：这是什么房间？这里出了什么事？从标出的门进来先看到什么？主会话拿回答和意图比，对不上的空间改布景重来，结果写进 `work/L<nn>/interior-review.json`：`[{"key", "answer", "match": true|false, "fix"}]`。同一个空间改了两次还对不上，停止重试，在 G9 消息里单列。先做几间、看过盲审结果再铺开同一栋楼的其余空间，能早点发现整批做错的问题。

## 产物

布景设计文件；布景平面图；`build/L<nn>/placements.json`（摆放记录）；俯视核对图 `build/L<nn>/check/placement_*.png`；房间布置图 `build/L<nn>/check/room_*.png`；室内盲审记录 `work/L<nn>/interior-review.json`。

## 交给下一步

摆放记录 placements.json；灯具类模型的位置清单（脚本，从布景文件里的灯具组导出，带 lit），G7 按它放光源，不另找。

## 完成

剔除 0（出界、压路线、挡门、重叠）；摆放核对 0 条错；每组都有挂靠的 key 和参照编号，第 1、2 档的组都引用了设计数据；每个室内意图的 `has` 每项都有组或写了不做的理由；每个空间都有房间布置图和盲审记录，盲审全部对得上（改两次仍对不上的单列交 G9）。脚本未覆盖的项，由本步 agent 核对，结果写进 `work/L<nn>/manual-checks.md`。

## 子 agent

**主模型档**：室内盲审，一栋楼一个，只给房间布置图，交回每个空间的三个回答。

## 常见坑

- 随机撒点：没有设计意图。
- 按“每个 key 挂了布景组”交差：覆盖率全过，房间还是看不出是什么。
- 所有房间沿用同一套墙地顶，房间之间只差几件家具。
- 布景写死坐标：设计一改就落空（要挂在空间、门、路线上）。
- 规范只写“做什么”不写“怎么摆”：生成器自己发挥，随机转角、成片侧翻。
- 没有俯视核对图：摆错只能靠负责人在编辑器里发现。
- “看得出出了什么事”这种写法：每段都撒血迹，痕迹和设计对不上。
