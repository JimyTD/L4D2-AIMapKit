# D0 详设准备（项目级，只做一次）

**目的**：定下所有关共用的尺度目标和分工，避免并行的几关各定一套。

## 做

1. **尺度目标**：用 `kit game measure <原版地图> <笔刷实体类名或模型路径>` 量原版地图的同类空间，包括走廊、门、楼梯、层高、封路高度。量完写进待决定列表里 `step: "D0"` 的项，依据写进 `why`（如 `game:c1m1_hotel ...`）。最低值只给有意做窄的地方用，常规空间按量到的目标做。用法见 [tools.md](../tools.md)。
2. **地面类型清单** `ground_types`：这张地图用哪几种地面，每种写 `id`、能不能走（`walkable`）、默认标高。
3. **跨关共享的结构体**：列出衔接安全屋所在的结构体，以及多关都会用到的结构体，每个指定一个写入关（先用到的那一关）。写入关负责设计这个结构体，其他关只引用、不改。衔接安全屋所在的房间先在这一步定下来。
4. **并行主线**：用户决定同时做几关，不超过 `kit.local.json` 的 `max_parallel_lines`。每关新开一个会话，用主模型跑。在 `PROJECT.md` 的“主线分工”登记每一关归哪个会话。开会话的方法见 [subagents.md](../subagents.md)。

## 完成

用户同意尺度目标、地面类型、共享结构体分工和并行数，然后跑 `kit approve D0`。
