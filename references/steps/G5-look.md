# G5 外观、模型与地标（每关一次）

**目的**：材质、立面、自制模型、地标按参照做到成品，模型和贴图编译后核对。这一步只有脚本门槛。G5、G6、G7 在同一次生成里一起跑，分开检查。

## 读

G2 的参照板 `work/refs/refs.json`（外观类型、自制清单）；G3 的构件记录 `build/L<nn>/parts.json`（G4 已并入实体记录）；美术规范（材质、模型、摆放、标识）。

## 做

1. 每个结构体按 refs.json 的 types 里它所属的外观类型定风格（外墙、立面、门窗框、压顶、标识），风格配置里写参照编号。
2. **立面贴图**：凹进的结构和不能通行的开口都画在这里（G3 的预算规则依赖它）。参照板里这一类型有照片的，做透视校正、裁切、按开间拼；没有照片的，用 Blender 程序材质按开间参数烘焙。每张写来源（照片编号或“程序生成”）。
3. **表面细节**：墙裙、踢脚、门框窗框、路缘石、地砖拼缝，不能一整面平铺。
4. **结构细节**用模型和贴花：栏杆、窗台、设备机位、管线、扶手、招牌。
5. **自制模型**：部件表 → Blender 后台 → 多角度渲染回读、和参照照片比对 → SMD → studiomdl → 打包。每个模型附参照编号和预览图；部件表、Blender 脚本、自制贴图源图放 `work/assets-src/`。
   - **坐标约定**写在美术规范里，所有模型一致（例：正面 +x，沿墙、沿线的方向是 y）；摆放代码按这个约定算朝向。
   - **精细档位**按美术规范的三档定，三角面数超出所在档的范围就报错。
   - **编译后核对**（脚本）：读编译出来的模型外包盒，和部件表的外包盒逐项比，对不上就报错、不进地图。编译工具会改变模型朝向，只看编译前的预览图查不出来。
   - **碰撞**：用模型自带的碰撞体（单独做的凸包），不在模型外面另包不画的 brush。设计数据里，物件（fixtures、objects）blocks 为 true 并且 vault 为 false 的，以及封路（blockers）和 boundary 里 kind 为 barrier 的段 cross.survivor 为 false 的，才在数据外包上加 playerclip。
6. **地标**按参照做专用外观；地标级模型的三角面范围按精细档位。
7. **自制贴图编译后核对**（脚本）：VTF 是 7.4、尺寸是 2 的幂；每个面上贴图的宽高比和面的宽高比相差不超过 texture_stretch_max，超了就是被拉伸；**文字不镜像**：贴文字贴图的面，先把 VMF 里的 uaxis、vaxis 各乘上它们缩放值的正负号（缩放为负会翻转方向），再算 u × v，它和面的朝外法向点积为负才是正的，为正就是镜像。
8. **按构件记录逐项关闭**：按部位槽和外观类型统一指定（例：“某一类建筑的门扇全部用同一种木门”，一条关掉一整类），例外的按 key 单独指定。不再按名字关键词猜；via 为“匹配失败”的条目必须处理掉。made_by 为 shell 的行同样要做到成品。

## 产物

- `work/style.json`：项目共用的风格配置，`{"slots": {"<部位槽>": {"<外观类型>": 材质或模型}}, "overrides": {"<key>": 材质或模型}}`，每条写参照编号。
- `work/models.json`：模型清单，`[{"path", "size_u", "tier", "axis_ok", "refs"}]`。
- `work/licenses.json`：素材来源和许可记录。
- `work/assets-src/`：自制资源的源文件。
- materials/<项目>/、models/<项目>/（编译产物）；模型预览图。

## 交给下一步

构件记录里外观类条目的状态更新（白盒 → 成品），每条写参照编号；模型清单 models.json，G6 只从清单里取模型摆。

## 子 agent

**主模型档**：自制模型一件一个子 agent（部件表、建模、渲染回读、编译后核对），交回模型路径、预览图、参照编号。**轻量档**：在原版资源包里按需求找候选模型，交回路径、尺寸、能不能做静态道具；主 agent 选。

## 完成

- 缺资源 0；静态道具都能用。
- 自制模型编译后外包盒和部件表一致，三角面数在所在档位范围内。
- 自制贴图编译后核对 0 条错。
- 构件记录里外观类条目没有“匹配失败”；每项都有参照编号。

没有脚本的核对项，由本步 agent 看预览图逐张查，结果写进 `work/L<nn>/manual-checks.md`。

## 常见坑

- 标识文字写反（包括用负缩放翻转的）。
- 原版模型没按静态道具编译，vbsp 直接删掉。
- Blender 材质槽顺序错了颜色就错位。
- 精细程度每关重新问一遍：档位没写进规范。
- 只看编译前的预览图：编译后模型转了 90°，摆进地图全部朝错。
- 模型外面另包不画的碰撞 brush：模型一转向，看不见的墙留在原处。
