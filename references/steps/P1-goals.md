# P1 定目标与规模

**目的**：定方向，只问只有用户能定的事。

## 做

用一份问卷一次问完，不要一条一条地问：

1. 真实度：复刻（真实地点，按实际布局）、借景（真实地点，自由改动）、虚构（没有真实依据）。
2. 几关，每关大约玩几分钟（下限、上限）。
3. 每关一句话体验，以及整个战役的体验曲线（哪里紧张、哪里放松、终局是什么）。
4. 一句话卖点。
5. 目标与非目标：明确不做什么。
6. 真实地点：大致范围（写 `geo.bbox`，供 P2 采地理数据用）。

现场事实不在这一步问，留到 P2 去查；也不在这一步切关。

## 产出

- `design/plan/campaign.json`：

  ```json
  {"title": "", "subtitle": "", "realism": "replica | inspired | fictional", "levels": 5,
   "minutes_per_level": [10, 15], "pitch": "", "non_goals": [""],
   "geo": {"bbox": [南, 西, 北, 东]}}
  ```

- `DESIGN.md` 第 1–3 章：目标与规模、卖点与非目标、体验曲线。

## 完成

`kit check campaign` 通过，用户确认后跑 `kit approve P1`。

## 常见坑

- 目标没定就开始画图。
- 把“包含某个地标”当目标。目标应该是“在那里玩什么”。
